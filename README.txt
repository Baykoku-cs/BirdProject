Птичья Дубна — версия для GitHub Pages

Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория GitHub: index.html должен лежать на верхнем уровне. ZIP-архив предварительно распакуйте.

В настройках репозитория: Settings → Pages → Build and deployment → Deploy from a branch → выберите ветку с файлами и /(root) → Save.

GitHub выдаст адрес сайта. Сайт будет доступен всем по ссылке; вход через ChatGPT не нужен. После публикации проверьте карту, фильтры и карточки.

Установка зависимостей, сборка, Python и Sites не нужны для опубликованной страницы. Для просмотра на компьютере используйте HTTP-сервер, а не file://.

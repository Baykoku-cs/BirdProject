# Птичья Дубна

Интерактивный атлас наблюдений птиц Дубны и окрестностей.

- 626 наблюдений, 108 видов, 2020–2025 годы.
- Территория: Дубна и зона в пределах 3 км от городской границы.
- Километровая сетка, фильтры видов и сезонов, фотографии и аудиозаписи.

Границы, сетка и пространственные связи подготовлены в QGIS. Веб-карта использует Leaflet и Leaflet.markercluster.

Данные и медиа: авторы iNaturalist; индивидуальные лицензии и ссылки указаны в карточках наблюдений. Подложка и границы: © OpenStreetMap contributors, ODbL. Иллюстрации видов созданы с помощью ImageGen. Лицензии библиотек находятся в `vendor/`.

Сайт статический. Для GitHub Pages: ветка `main`, папка `/ (root)`. Для локального просмотра нужен HTTP-сервер, например `python3 -m http.server 8000`. Подложка и медиа требуют подключения к интернету.
